# Content Generation

Generate engaging social media content that sounds human, not robotic.

## Twitter/X Best Practices

### Character Count

- **Sweet spot**: 71-100 characters (highest engagement)
- Max: 280 characters
- Shorter = better

### Human Tone Patterns

Start with natural phrases:

- "Been playing with..."
- "Just found out..."
- "Hot take:"
- "Unpopular opinion:"
- "Finally figured out..."
- "Actually pretty cool that..."
- "Is it just me or..."

### Content Types (by engagement)

1. **Questions** - "Anyone else using X? What's your experience?"
2. **Hot takes** - Controversial but defensible opinions
3. **Personal stories** - "I've been doing X for Y days..."
4. **Discoveries** - "Just discovered X can do Y. Game changer."
5. **Tips** - "Pro tip: [actionable advice]"

### Formatting

- Use **1-2 hashtags max** (don't over-tag)
- Add emoji for personality (1-3 per tweet)
- Line breaks for readability
- Tag relevant people/projects with @

### What to AVOID

❌ "Check out this AMAZING tool!!!"
❌ Overly formal/corporate tone
❌ Hashtag spam: #every #single #word
❌ Pure link drops without commentary
❌ Sounding like a bot

### Examples

**Personal Experience**

```
Been running OpenClaw locally for a week. Actually pretty nice having an AI assistant that doesn't send my data to random servers. The new Android support is clutch 🦞
```

**Discovery**

```
Just found out you can [specific feature]. No more [common pain point]! [link] #tech
```

**Hot Take**

```
Hot take: self-hosted AI assistants > cloud ones. Privacy + no subscription + actual control. Anyone else made the switch?
```

**Question/Discussion**

```
What's everyone using for [task] these days? Been using [tool] but wondering if there's something better. [context]
```

**Tip**

```
Pro tip: [specific actionable advice]. Saved me [time/effort]. Your welcome 😉
```

## Thread Techniques

For longer content, split into threads:

1. **Hook tweet** - Grab attention
2. **Context** - Why this matters
3. **Main content** - Tips/story/details
4. **CTA** - What should people do?

### Thread Hook Examples

- "I spent [time] doing X. Here's what I learned:"
- "Unpopular opinion: [view]. Let me explain:"
- "10 things I wish I knew about X:"

## Platform-Specific Notes

### Twitter/X

- Casual, conversational
- Embrace the chaos
- Quote tweets > replies for visibility

### LinkedIn

- More professional tone
- Share lessons learned
- "I'm excited to share..." patterns

### Instagram

- Visual-first (text supports image)
- Longer captions OK
- More hashtags (5-10)

## Content Ideation

When asked to generate content ideas:

1. **Trending topics** - What's hot in [industry]?
2. **Common pain points** - What problems do people have?
3. **Behind the scenes** - Show work/process
4. **Contrarian views** - Challenge popular opinions
5. **Resources** - Curate valuable links/tools
6. **Personal wins/fails** - Share experiences

## Quick Templates

### Launch Announcement

```
Finally shipped [thing]!

What it does: [1-line description]
Why it matters: [problem it solves]
Try it: [link]

Special thanks to @[contributors]
#[hashtag]
```

### Weekly Update

```
This week in [project/topic]:

✅ [accomplishment 1]
✅ [accomplishment 2]
🔄 [work in progress]
❌ [fail/lesson]

Next week: [goal]
```

### Tool Review

```
Been using [tool] for [time]. Verdict:

✅ [pro 1]
✅ [pro 2]
❌ [con]
❌ [con]

Great for: [use case]
Skip if: [use case]

[link] #review
```
