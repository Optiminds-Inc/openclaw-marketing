# Pre-Post Check

## MANDATORY RULE

**NEVER post/send anything without showing the user first and getting explicit approval.**

This applies to:

- Tweets / X posts
- Social media posts (LinkedIn, Instagram, etc.)
- Messages to others (email, chat, etc.)
- Any external communication

## Workflow

1. **Draft** - Write the content
2. **Show** - Display to user with character count
3. **Wait** - Ask "Ready to post?" or "Looks good?"
4. **Revise** - If user wants changes, edit
5. **Post** - Only after explicit approval

## What to Show

When drafting a tweet/post, always include:

- The exact text
- Character count
- Any hashtags
- Links/media included

Example format:

```
📝 Draft tweet (124 chars):

"Your tweet text here #hashtag"

Post this? (yes/edit)
```

## Why This Matters

- User might want to add/remove info
- Tone might need adjustment
- Important details could be missing
- User has final say on their public presence
